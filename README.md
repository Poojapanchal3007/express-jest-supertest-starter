# Express API Integration Testing

Coursework and practice repository for testing an Express to-do API with Jest and Supertest.

## Technologies

JavaScript · Node.js · Express · Jest · Supertest · JWT

## What the project demonstrates

- HTTP request and response testing
- Authentication checks for task creation
- Validation of missing request data
- An in-memory task repository

## Run the tests

```bash
cd server
npm install
npm test
```

See the [server documentation](server/README.md) for the teaching setup and project structure. This is an educational API; tasks are stored in memory.
